# MG quick-ref: the one home of every motion-graphics rule (owner decisions to 29 Sep 26)
Read this, then `learnings/mg.md`. [G] = a gate fails it (gate named). A bespoke diagram is a claim: brief it on `references/mg-brief-template.md` first; review order meaning, layout, motion, code gate. Library-first: search `library/catalog-index.json` or `npx hyperframes catalog --query "<intent>"`, browse `/gallery/` (`python3 -m http.server 8765` from `library/`), copy the closest block into the episode and hand-retune it per beat (`npx hyperframes add` lands in `library/official/`, never in an episode). Shipped patterns live in `references/editing-patterns/`; copy one there the session it ships.

## File contract
- One graphic = `compositions/g-<name>.html`: `<template>` + own `<style>` + root `data-composition-id` + a PAUSED gsap timeline at `window.__timelines["g-<name>"]` (`window.__timelines = window.__timelines || {}` first); file stem = composition id. [G graphics_qc no-timeline]
- Mount `<div id="host-x" data-composition-id="g-x" data-composition-src="compositions/g-x.html" data-start data-duration data-track-index data-width="1920" data-height="1080">`; never graphic DOM from `innerHTML` strings in index.html. Every comp mounted, every mount has a file [G sweep 6]; unique element ids [G sweep 5b]; comp timeline >= host window [G graphics_qc short-duration, 0.05 s].
- Comps render inside index.html's DOM: never reuse a class index.html uses [G css_collision via sweep]; bake inherited colour/font into the comp. Never `id="root"` / `#root` either: the host's `#root` rule (opaque background) lands on the comp root and blacks out the clip or comp beneath (ep-nepal 29 Sep 26, 8 comps); scope it, e.g. `id="<name>-root"`.
- Assets `media/x` (project-root relative). gsap is vendored per episode, no CDN; MotionPathPlugin is not bundled (use per-leg `attr` tweens).
- GSAP/WAAPI only, never CSS @keyframes (kills fast-capture). Every `set`/`to` has an explicit position. Never `repeat:-1` on a main timeline (duration 1e10); ambient loops use finite repeats. Tween transforms, never `width`/`height`/`letterSpacing`.
- No initial CSS transform on anything GSAP transforms (`tl.set` at 0); no static SVG `transform=` on a GSAP mover; nested SVG pivots use `svgOrigin`; dash lengths are `ceil(len)+1`, never typed. A path follower moves by GSAP only; assert it sits on the path head at three times.
- Text is pre-authored per element and toggled with autoAlpha: never written on a node with children, never in onStart/onComplete/onRepeat/`tl.call` (seek-based gates never fire them); onUpdate count-ups on a leaf span are fine. [G comp_lint R1/R2 via sweep]
- Delete `_shot_*`, `_dur_*`, `_debug_*` staging pages from `compositions/` before the gates.

## Type tiers
- Three tiers in every designed card: big >= 52 px, mid 26-51, small < 26 — these are the exact thresholds `graphics_qc` checks. [G graphics_qc flat-type: < 3 tiers with >= 4 text nodes]
- Exact hex, font stacks and per-tier px values (eyebrow, headline, serif sub, row value/label, counter, section header, diagram label, popfig): `library/inhouse/snippets/tokens.md` "Fonts" and "Type tiers" — the one home, do not restate them here. Proper case, never all-lowercase.

## Palette and surfaces (fixed meaning)
- Full palette (hex + role), surfaces and CSS custom-properties: `library/inhouse/snippets/tokens.md` "Palette" — the one home, do not restate hex here. An episode uses 10 of these or fewer.
- Text over footage: `.glasscard` (values in tokens.md) is the ONE treatment; no bare text on moving footage, no mid-beat swap to a dark card. Beige cite card (tokens.md) with dark text only for quoted sources over dark maps. No dark chip. Small text never carries a moment alone (BFMG): a quote card, cost list or headline pair is a glass card over footage; dark `c-*dark` fillers only for bridges of 5 s or less. Lower-third sub-lines high contrast.
- Dates and figures: red Abril popfig (text-shadow, 3 words or fewer, big line 16 characters or fewer, mid-screen), never a colour-block card; never over a card or a map comp (the card row or map rail carries the number).

## Motion and exits
- Something visibly moves for the whole window: a scan line at 6 px/s or more, dot blips at most 1.5 s apart, a rotating sweep (1.3 px/s drift reads as a freeze). Stillness: a gap of 4 s or more with nothing moving fails ([G] beat_density and graphics_qc idle); that is the only number, no warning tier.
- A graphic is a sequence, not a poster: reveal each element on its spoken word, build text line by line, then the finished graphic exits.
- New information lands on the narrator's words, not on a clock. A hold that waits for the next impact point is correct as long as something drifts: a slight up/down float on the elements is enough (owner 26 Sep 26; the tanker hold after landing, with only rain moving, is not a defect).
- A camera push/pull-out over ~1.5x uses `logZoom` (`library/inhouse/snippets/helpers.js`), not a
  plain linear `fromTo` on scale. Linear scale reads as uneven speed on a big move (a push-in slows
  down, a pull-out speeds up) since scale is exponential, not additive. A smaller move is fine linear.
- Panel in `fromTo(x:660 -> 0, 0.7, power3.out)`; rows `fromTo(autoAlpha 0, y:24 -> 0, 0.4)` ~0.6 s apart; bars `scaleX 0 -> 1`, `transformOrigin:"left center"`, 0.5 s; counters `to({v})` power4/power3.out writing a leaf, opening on the first tick's value, fast then slow into the final figure, secondary stat after. Punchy eases; at least one kinetic tween per two fades; fade-only fails [G graphics_qc].
- Exits: panels and cards slide out (`to x:980, autoAlpha:0, 0.6, power3.in`, overshooting the slide, anchored to the comp's last ~0.6 s; check a frame at host end minus 0.5 s). A full-frame MG scene may end on a camera move, fade-through or cut, never a hard vanish of a single element mid-frame. ~1 s land time after the last beat, never cut on motion. Duration = max(declared, last cue + tail), never estimated.

## Text doctrine (owner, 26 Sep 26)
- Like a medical or physics diagram: "they will just draw a line and mention the name of it", a figure reference, or an equation. No paragraphs, no stacked eyebrows. Narration carries the explanation ("the report writing"). One reading target at a time.
- No text rides a camera shake or parallax move: text lives on a fixed HUD layer and enters when the motion settles.
- Every MG is cued to the narration beats (`audio/<seg>.words.json`), not estimated, with the spoken time in a comment (`/* FUEL @4.74 */`). A graphic never starts before its trigger or after a blank gap. Reveals follow the voice's order and wording ("SOME HAD NO MONEY"). Whisper writes digits, so cue phrases do too. Numerals on screen, words in the voice.
- Eyebrow only when it names the thing ("EF5 THRESHOLD"), never decoration, never a number pre-reveal. Name things unambiguously ("WHAT THEY EXPECTED · ROPE FUNNEL"). One idea per frame, no stat spray; one fact, one instance per frame [G overlap_check dup-fact]. One label on several different things at once (a rating tag on each track, a source credit under each quote), or a place name that happens to carry a digit ("US-81" on the map and again beside its clock time), is not a repeat: declare it with `data-repeat-ok="reason"` on the label's own leaf (`<text>`, not a `<tspan>`; never a wrapper, which would waive every figure under it). A declared leaf is compared with nothing, so declare only after a frame read. Comp text only: index overlays and cards cannot be declared.
- Build the mechanism, animate it, let the label name it (a cone captioned "tornado" conveys nothing). A person card without a real photo drops the photo slot (text only, no monogram). A strike goes through the glyph; every child stays inside its card.

## Gate-readable authoring (what the gates parse; run all with `python3 scripts/run_gates.py episodes/<slug>`)
- [G beat_density.py] Reads the BUILT timeline (`scripts/beat_probe.mjs`, staged like graphics_qc; the rule is `stage_comp.mjs` motionSpans, shared with graphics_qc idle), so helpers, aliases and loops are seen. Motion = a tween animating a property of a DOM/SVG element, over its start to start + totalDuration (`repeat:n` included, `repeat:-1` runs past the host) when a target is seen at the span's midpoint (rendered, not opacity 0, overlapping the frame: a tween on a `display:none` node is not motion); the canvas-renderer rule below; or any 0.1 s step where a seen element's box, transform, opacity or own text changes with the timeline's onUpdate firing (moves' onFrame hub, proxy counters, `tl.call`; a write to `dataset` or a hidden node is not motion). A tween on a plain object (`tl.to({}, {duration: N}, 0)`, an unread proxy) or with no animated property is not motion: a clock sets the timeline length, it never passes this gate. Hosts are read per tag (`data-composition-id` + numeric `data-duration`, any order). FAIL at a gap >= 4.0 s, including before the first beat and after the last span, and on any comp the probe cannot measure (ERROR).
- A canvas painted from a tween-level `onUpdate` is invisible to the motion gate (the step diff cannot see pixels): drive the canvas from `tl.eventCallback('onUpdate', ...)` as `library/inhouse/webgl/tornado.html` does.
- [G sweep check 7] Positions parse as `tl.x(..., <number>);` with no `;` inside the call. FAIL when the host outlasts the timeline by > 4 s ("holds") or cuts the last discrete beat by > 0.30 s (tweens > 4 s with `ease:"none"` are continuous, not beats). Check 9: stills > 6 s fail.
- [G graphics_qc.mjs] Kinetic props: scale, scaleX, scaleY, x, y, rotation, width, strokeDashoffset, attr; a canvas covering a quarter of the frame or more counts as a designed background, and with a timeline-level `onUpdate` it also counts as one kinetic span over the whole comp (WebGL comps; the gate does not check that the callback draws). Hide/exit = opacity or autoAlpha 0, |x| or |y| >= 1000, a 100-999 % string, |xPercent| or |yPercent| >= 100. Hard: fade-only, text-collision (glyph boxes overlap > 45 % of the smaller height and > 35 % of the smaller width), out-of-frame (glyph > 24 px outside), bad-crop (cover image > 200 px wide losing > 35 %), empty-container, broken-image, short-duration, js-error, idle (4 s or more with nothing moving by the beat_density rule, `stage_comp.mjs` motionSpans, so a `{}` clock is not motion; measured over the host window, or the timeline when unmounted), undesigned (3+ of: no gradient or backdrop blur, < 3 tiers, < 25 % kinetic, < 12 elements, > 60 % frozen). Warnings: thin-motion, limp-easing, no-continuous-motion. Samples sit in [0.4 s, duration - 1.0 s], so a comp under ~1.4 s is never measured. Staging (`scripts/stage_comp.mjs`, shared with beat_density, overlap_check and occlusion_check) injects index.html's `<style>` and `<script src>` tags (GSAP plugins) and sets `<base href="../">`, so `media/x`, `../media/x` and `vendor/x.js` all resolve against the episode root.
- [G overlap_check.mjs] Leaf = a div/span (text/tspan in comps) with no children or only em/b/i/strong/sup/sub. Steps 0.5 s from 0.4 s; FAIL when two visible leaves (opacity >= 0.15) intersect > 25 % of the smaller box: comp-internal, overlay-on-comp, sandwich (track-3 card zone over comp text), card-vs-card. Dup-fact: the same digit-bearing text of 3+ characters (uppercased, punctuation dropped) on two visible leaves at one step; a comp node with `data-repeat-ok` on itself or an ancestor is left out of the count entirely. Overlays = every timed index element that is not a comp, not track 3, id not `bo-/nx-/sx-/clip-/v-`. Off-frame: an overlay leaf left < 0, right > 1920 or scrollWidth > clientWidth + 2, with transforms reset (a runtime x tween is not caught). Wrap every overlay (popfig, chip, source label, quote card) in a timed `<section|div id="..." data-start data-duration data-track-index>`: overlap_check ignores an unwrapped overlay (0 overlays, false PASS).
- [G blank_scan.mjs] 0.25 s steps; ink = visible text/img/video/canvas/svg leaf area (ids or classes containing "drift" excluded); FAIL below 0.4 % of the frame (8,294.4 px sq) for >= 0.75 s.
- [G occlusion_check.mjs] Hosts must match `<div ... id="host-..." ... data-composition-src="compositions/...">`. An upper-track box with background alpha >= 0.5 and > 300 x 120 px covering > 8 % of a lower comp's text leaf fails (two-letter caps labels exempt); staged through `stage_comp.mjs` like graphics_qc (host CSS, episode-root paths).
- Minis also run `node scripts/freeze_scan.mjs episodes/<slug>` (fails holds >= 6 s by default).

## Verify: gates, then settled frames over the real footage, before any render
- Code states duration, tweens, position, size, colour, tiers and text; the gates assert them in the DOM. Gates passing is not verification: blank_scan counts DOM boxes and graphics_qc stages each comp alone on a blank stage, so neither sees an empty frame or text that will not read over the footage beneath.
- Every NEW or changed comp, pre-render: `npx hyperframes@<pin> snapshot episodes/<slug> --at <t1>,<t2>,<t3> --no-end --describe false -o <dir>` (pin = `config.yaml hyperframes_version`; `--describe false` stops the default Gemini call). It renders index.html with the real footage beneath at episode-time seconds, no render needed. Three settle frames: reveal done, mid-hold, pre-exit (comp-local times in `episodes/<slug>/.qc-tmp/frame_times.json` from graphics_qc; add the mount's data-start; a frame a higher-track cutaway covers moves to the latest uncovered moment before it); never a fixed-interval sweep.
- Any crop, zoom or position change on a clip or graphic gets a fresh frame read before the render, even a one-number edit: a looser crop can expose a logo or watermark (ep-nepal: the 7NEWS zoom).
- An Opus verifier who is not the builder reads the frames (never the main context), then the orchestrator reads one frame per graphic (roles: CLAUDE.md "Chain of command for motion graphics"). It FAILS garbled or cut-off text, an element out of frame or hidden, a frame mostly empty or black ("Frame coverage"), text that does not read over its footage, a picture contradicting the narration, or nothing moving where motion is due; shifts < 8 px, timing < 0.2 s and taste are owner notes.
- Two fix rounds per comp, then ship and list the rest. Never build a measuring rig a gate already answers; a hole in a gate is fixed in the gate.
