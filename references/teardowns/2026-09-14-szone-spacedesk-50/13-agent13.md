**(a) One-man daily production recipe (time budget/episode, ~2.5-3hr total)**
Fact-pull from NOAA/CPC/NWS pages same day: 15min. Script to 8-beat skeleton at 190 wpm target (length x wpm = word count): 60-90min. TTS render at matching wpm: 10min. Visual sourcing — stock/PD B-roll + the one named NOAA/CPC/NASA chart per thumb spec, popfig text layer for numbers/city names only, zero motion graphics: 20min. Assembly/render: 30min. Thumbnail build (School B/C per spec): 15min. Publish checklist: title ≤52 chars with search phrase in first 40, no ALL-CAPS words, description with linked sources, end-screen to prior episode, schedule next-day slot: 10min.

**(b) Reusable 8-beat skeleton + seam phrases (humanise-compliant, no em dashes/rhetorical Qs/reveal-flips/drama-stacks)**
1 Open: "[Number]. That is [what it measures]." 2 Promise: "I am going to show you [X] before this is over." 3 Event: "Right now/As of today, [what happened]." 4 Mechanism: "The reason comes down to [cause]." 5 History: "This happened before, in [year], and [result]." 6 Stake: "For [place], the practical effect is [consequence]." 7 Debunk: "That is not the same as [myth]. The record shows [fact]." 8 Close: "Watch for [date]. That is when we will know [question]."
10 phrases never to use: "here's the thing"; "here's/here is what's coming"; "stay with me"; any rhetorical question as a hook device; "is this the [X] we've been warned about"; "nobody is talking about this"; "that is not a coincidence"; stock reveal-flip ("It was not."); drama-stack triads ("Not X. Not Y. Not Z."); "you aren't ready to hear this."

**(c) Publish order and hold logic**
Daily 9/15-9/23: Ep1 (highest-authority number, builds trust) → Ep2 (rides real hurricane-peak news cycle, named places per Szone's own data showing vague titles cost 8x views) → Ep3 TX → Ep4 CA → Ep5 Dixie Alley → Ep6 FL → Ep7 Northeast (population-weighted regional order) → Ep8 myth/trust episode placed once comment pushback typically starts → Ep9 water/ag as a low-urgency close before the pause. Hold Ep10/11/12 for Oct 8, Oct 16, Nov 12 — each rides a real, dated, verifiable release exactly like SpaceDesk's eclipse/moon-impact wins (23.5x and 3.6x median), the single highest-leverage device in both channels' data.
