# grader-calibration.md: the independent grader's rubric, taught from the owner's own picks

The independent grader (`learnings/script-process.md` "independent grade on every script") used to give one 0-10 number against a bar of 8. On 26 Oct 26 it gave 7 of 9 hooks a 7 and stopped moving. This file replaces the single number with named pass/fail checks, each taken from something the owner said, and keeps the 24 past verdicts the checks were tuned on. Owner approval: devq `ap_grader`, 26 Oct 26 ("alongwith the suggestions im giving. would be nice. later if needed, we can update it per actual data we get from youtube.").

**Re-tune later.** The rubric is re-tuned from real YouTube results (retention, AVD, click-through) once a few videos made under it have data. Until then the owner's verdicts below are the only ground truth. Add a row to the set whenever he accepts or rejects an item with a reason; reword a check only when a row proves it wrong.

## How the grader uses it
1. Run every check that applies to the item's kind (table below). Each is PASS, FAIL or NA.
2. The item passes only if no applicable check FAILs. The owner-facing report names the failing checks, not a score.
3. The grader never sees the writer's reasoning, and never sees this set's verdict column when grading a new item.
4. HK3 needs the hooks written before it in the same batch; without them it is NA.
