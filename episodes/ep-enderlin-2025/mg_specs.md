# ep-enderlin-2025 · MG specs (27 Sep 26)

One block per NEW composition family. A comp file mounts ONCE (it owns its element ids and its `window.__timelines` key),
so a family that returns later gets one file per window: the first window keeps the family name, reuse windows add a suffix.
Every listed file exists now as a **placeholder (to build)**: a valid comp with the right id and duration, one drifting card,
so the gates run. The builder replaces the whole file and keeps the id, the root `data-duration` and the host window unchanged.
A window change goes back to the editor (`index.html` host + `shot_map.md`), never silently in the comp.

**Read before building (every builder):** `references/mg-quickref.md` (all rules, gates), `learnings/mg.md`,
`library/inhouse/snippets/tokens.md` (the one palette/type home), and this block. House rules the placeholders do not show:
- Hosts sit on track 2 (full frame) or track 4 (overlay). Text-safe margin 96 px left/right, 54 px top/bottom. No presenter circle in this cut.
- Every cue from `audio/<seg>.words.json`. **Times below are EPISODE seconds; local time = episode time - host start.**
  Whisper runs up to ~0.08 s early; land a hit on the word, never before it. Write the spoken word in a comment (`/* EF5 @12.93 */`).
- Numerals on screen, words in the voice. Proper case. Three type tiers (small < 26, mid 26-51, big >= 52 px). Glass card
  for text over footage; beige cite card only for quoted sources over dark maps. One idea per frame.
- Something visibly moves the whole window (scan line >= 6 px/s, blips <= 1.5 s apart, drift); no gap >= 4 s. Finite repeats only.
- Exits slide out (x 980 / y -40, autoAlpha 0, power3.in) in the last ~0.6 s, or the comp ends on a camera move / fade-through.
- On-screen words must pass `scripts/flag_words.py` (no "killed", "dead", "deaths"; use "lives lost", "did not survive").
- Honest claims only: every figure below is from `fact_check.md` / `research/fact_sheet.md`; do not add numbers that are not listed.
- Delete `_shot_*`, `_dur_*`, `_debug_*` pages before handing back. Gate: `python3 scripts/run_gates.py episodes/ep-enderlin-2025`.

Library starting points: `library/inhouse/` (ef-ladder, stat-timeline, ranked-bars, stat-panel, numbers-rollup,
bulletin-typewriter, outro-brand, title-card), the moves library `library/inhouse/moves/` (arcThrow, measureDraw, bandCompare,
counter, slamFig, impactRing, lightning, cameraRig, cleanExit), the WebGL tornado `library/inhouse/webgl/tornado.html`,
`library/catalog-index.json` (`npx hyperframes catalog --query "<intent>"`), shipped patterns in `references/editing-patterns/`
(ep3-map-route-fit, ep5-terrain-map, ep2-met-explainer, ep6-glasscard-popfig-bfmg), and ep-1974's comps
(`episodes/ep-1974-super-outbreak/compositions/`: g-map-*, g-radar-*, g-cite-*, g-person-*, g-thennow-*, g-f4f5, g-scale-*).
