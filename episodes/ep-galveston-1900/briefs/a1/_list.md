## Shared rules (every brief in this folder points here)
### Words and times
- Every cue is seconds from the start of that segment's wav, read from `audio/a1-s<n>.words.json`. Whisper writes "Klein" for Cline and digits ("1891.", "16th", "5 .2"); on screen it is always CLINE.

- index.html has no a1 mounts yet. Host `data-start` = that segment's `nx-a1-s<n>` `data-start` plus the brief's first cue. A comp spanning segments: comp-local time of a word = (that segment's `nx` start − host start) + word time. Never assume the gaps between segments; read them from the mounts.
- The act is locked; if a segment is re-voiced, retime from the new words.json, never by offset.

### Placement (1920 x 1080)
- Source line: TOP-LEFT, `left:96px; top:54px`, Arial 700 19 px `#c8d3e0`, glass surface (tokens.md "Surfaces", radius 12), padding 6px 14px, max width 900 px, two lines allowed.

- Lower-third: `left:110px; bottom:110px`, name Arial Black 900 52 px `#f2f5f8`, role Arial 700 27 px `#f5d98b`, one glass card, padding 18px 28px, `display:table`. Enter `fromTo(x:-60, autoAlpha 0 -> x 0, autoAlpha 1, 0.6, power3.out)`; exit `to(x:-980, autoAlpha 0, 0.6, power3.in)`.
- Chip: one glass card (radius 28), main line Arial Black 900 (size per brief; 44 px default) `#f2f5f8`, optional tag line Arial 700 22 px `#93a3b2` tracking 4. Enter `fromTo(y:24, scale 0.94, autoAlpha 0 -> y 0, scale 1, autoAlpha 1, 0.45, back.out(1.6))`; exit `to(x:980, autoAlpha 0, 0.6, power3.in)`, on a map or diagram `to(y:-24, autoAlpha 0, 0.4, power2.in)`.
- Popfig: cards.css `.popfig`, `AbrilFig` (vendor `fonts/AbrilFatface-Regular.ttf`), big line 150 px `#d0121f` with the cards.css text-shadow, sub line Arial 700 32 px `#e8e3d8`. - Drift: every visible text card floats y ±4 px, `sine.inOut`, 2.4 s yoyo, finite repeats sized to the host, from its land time.
