Every element id is prefixed `g-<name>-`.
- Background: `radial-gradient(ellipse at 50% 45%, #0b1016 0%, #030507 78%)` unless the brief says the comp floats over footage (then root transparent and text on `.glasscard`).

Reveals `fromTo autoAlpha 0, y:24 → 1, 0 (0.4 s)`. Bars grow `scaleX 0→1, transformOrigin "left center"`. One CONTINUOUS element for the whole duration (slow drift, sweep, scale push); no stretch > 3 s without a visible change (≤ 2.5 s in the first 10 s). Every `tl.set`/`tl.to` carries an explicit position.
- Cues: the narration for each segment is `audio/<seg>.txt` and its word timestamps `audio/<seg>.words.json` (on the SPED wav, atempo 1.10, so these are final). Put every cue in a `const CUES = { … }` block at the top of the script with the spoken word in a comment, e.g. `f6: 3.42, // "six"`. If a words.json does not exist yet, set the cue from the word's position in the .txt at the segment's measured wpm from `audio/manifest.json` and mark it `// PROVISIONAL`; report the provisional list in your receipt.
- Comp duration = host window; the brief gives the window as the segment span (segment start = 0). The orchestrator mounts the host and may trim.
- Text over footage: `.glasscard` (rgba(10,16,24,.55), blur 18px, 1px rgba(255,255,255,.14) border, radius 28). Dates and figures that the index already shows as red popfigs are NOT repeated inside a comp (one fact, one instance).

Screenshot loop: stage the template into a bare page with `../gsap.min.js` (copy `scripts/_shot_comps.mjs` to a scratch file with your own plan) and read 4–6 frames; then run `node "<worktree>\scripts\graphics_qc.mjs" .` from the episode dir.
