## Latest official toll
As of this research pass (29 Sep 2026, this session's searches), no NDRRMA statement specific to the Sept 26-29 event and dated later than 28 Sep was found. The most recent NDRRMA-linked figures for the NEW September event (distinct from the August cumulative 1,451 dead / 5,745 missing, which is a different disaster):

- Higher counts circulating same window (NewsBytes 24/14, unnamed-source ANI/SANA 21/5/5) are not clearly NDRRMA-sourced and should be treated as press aggregation, not the official figure.
**Recommend leading the script's "established" toll with the Al Jazeera/NDRRMA 12-to-14 dead range (27-28 Sep) and footnoting the higher unconfirmed counts**, consistent with the flag already in nepal-sep27/notes.md.

## Untagged errors noticed (not covered by a [verify] tag in this slice)
1. **Himlung peak height inconsistency risk:** multiple sources give Himlung Himal as 7,126 m; if another section of the script (outside my slice) states a different figure, it should be reconciled to 7,126 m.
2. **"Sherpa climbers" (L431, tied to tag #25 above):** worth flagging beyond the tagged claim — using "Sherpa" as a generic label for any Nepali high-altitude worker is a common but inaccurate journalistic shorthand; none of the four confirmed dead are sourced as ethnically Sherpa. Recommend "guides and kitchen staff" or "Nepali support crew" throughout A6/Z rather than "Sherpa" unless a source specifically confirms it.
3. **River-blockage claim (tag #12) also affects the A6 sensor-gap framing:** since the Kali Gandaki dam-and-breach is now an established fact, not unknown, it strengthens (rather than undercuts) the episode's "which hazard type was the system built for" argument — worth a note to the editor, not a script rewrite call for fact desk C.
